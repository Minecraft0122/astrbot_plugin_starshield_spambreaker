# astrbot_plugin_keyword_matcher

一个用于 AstrBot 的关键字匹配和刷屏处理插件，可以检查发送者用户名和消息正文是否包含指定文字，也可以检测同一用户短时间内重复发送相同文本、图片或表情。命中后可自动回复、写日志、撤回刷屏消息，也可以阻止后续插件或 LLM 继续处理。

## 安装

把本目录放到 AstrBot 的 `data/plugins/astrbot_plugin_keyword_matcher` 下，然后在 AstrBot WebUI 的插件管理里重载或重启 AstrBot。

## 配置

在插件配置页填写：

- `用户名关键字`：每行一个关键字，留空则不检查用户名。
- `消息关键字`：每行一个关键字，留空则不检查消息正文。
- `匹配模式`：`any` 表示用户名或消息任一命中即可；`all` 表示已配置的项目都必须命中。
- `命中回复`：留空则只记录日志不回复。支持 `{name}`、`{message}`、`{field}`、`{keyword}`。
- `命中后阻止后续处理`：开启后会阻止其他插件和 LLM 继续响应该消息。
- `启用重复刷屏撤回`：开启后会检测同一用户在短时间内反复发送相同内容。
- `重复触发次数`：默认 5 次，同一用户在时间窗口内发送同一内容达到次数后触发。
- `重复检测时间窗口（秒）`：默认 30 秒。
- `撤回窗口内全部重复消息`：默认开启，达到阈值时尝试撤回窗口内记录到的重复消息；关闭后只撤回当前消息。
- `重复刷屏命中后阻止后续处理`：默认开启。

## 撤回说明

AstrBot 的通用事件接口没有统一撤回方法，本插件按官方旧版开发指南里的方式调用 OneBot API：

```python
await event.bot.api.call_action("delete_msg", message_id=event.message_obj.message_id)
```

因此自动撤回目前只支持 `aiocqhttp` / OneBot 适配器，并且机器人账号需要在对应群里拥有撤回权限。其他平台命中重复刷屏时会记录日志并阻止后续处理，但不会真正撤回。

示例：

```text
用户名关键字：
管理员
测试号

消息关键字：
退款
投诉

命中回复：
已检测到关键词：{keyword}
```
