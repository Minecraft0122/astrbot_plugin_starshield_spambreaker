# 星盾·刷屏终结者

这是一个 AstrBot 反刷屏插件。它不依赖“同一内容累计发送 5 次”这种容易绕过的计数，而是按平台、会话和发送者分别维护有限历史，检测以下情况：

- 最近一条消息在短时间内再次完全重复，第二条立即拦截。
- 消息主体基本相同、只在末尾追加随机字符，且发生在短时间窗口内，按近重复拦截。
- 单条消息包含大量连续重复片段，例如 `神经病神经病神经病神经病`。

命中后会调用 `event.stop_event()`，阻止后续插件和 LLM 继续处理。启用撤回时，`aiocqhttp` / OneBot 适配器会调用 `delete_msg` 只尝试撤回当前命中的新消息；其他平台没有统一的撤回接口，但仍会阻止后续处理并记录日志。

## 安装

将插件目录放到 AstrBot 的 `data/plugins/astrbot_plugin_keyword_matcher` 下，在 WebUI 中重载插件或重启 AstrBot。

## 默认策略

- 完全重复：同一用户上一条消息在默认 60 秒内规范化后相同即命中。规范化会处理 Unicode 兼容形式、大小写、连续空白和零宽/控制字符。
- 随机尾缀：默认只回看 60 秒内的近期消息；主体至少 12 个字符，公共前缀至少占较短消息 75%，差异尾部总计不超过 64 个字符，并且尾部符合常见随机 ASCII/Unicode 标记特征；即使尾缀只有 1～3 个 ASCII 字符，只要每条消息都在变化也会拦截。
- 单条重复：同一片段连续出现至少 4 次、总重复长度至少 12 个字符，并覆盖消息至少 60%。

所有检测阈值都可以在插件配置页调整。`max_recent_messages`、`max_senders` 和缓存过期时间用于限制内存使用。

## 说明

“随机尾缀近重复”只比较时间窗口内近期消息的公共前缀，不会删除原文，也不会把任意数字或英文内容一律当作随机字符。因此正常的不同问句、版本号或邀请码仍有机会被区分；如果实际群聊内容更短或更长，可以调低/调高 `near_duplicate_window_seconds`、`near_duplicate_min_chars`、`near_duplicate_prefix_ratio` 和 `near_duplicate_max_suffix_chars`。

单条重复检测采用有界周期扫描，不使用可能发生灾难性回溯的正则表达式。超长消息只扫描有限首尾部分。
