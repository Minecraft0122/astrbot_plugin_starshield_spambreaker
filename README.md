# astrbot_plugin_keyword_matcher

一个用于 AstrBot 的关键字匹配插件，可以检查发送者用户名和消息正文是否包含指定文字。命中后可自动回复、写日志，也可以阻止后续插件或 LLM 继续处理。

## 安装

把本目录放到 AstrBot 的 `data/plugins/astrbot_plugin_keyword_matcher` 下，然后在 AstrBot WebUI 的插件管理里重载或重启 AstrBot。

## 配置

在插件配置页填写：

- `用户名关键字`：每行一个关键字，留空则不检查用户名。
- `消息关键字`：每行一个关键字，留空则不检查消息正文。
- `匹配模式`：`any` 表示用户名或消息任一命中即可；`all` 表示已配置的项目都必须命中。
- `命中回复`：留空则只记录日志不回复。支持 `{name}`、`{message}`、`{field}`、`{keyword}`。
- `命中后阻止后续处理`：开启后会阻止其他插件和 LLM 继续响应该消息。

示例：

```text
用户名关键字：
管理员
测试号

消息关键字：
退款
投诉

命中回复：
已检测到关键词：{keyword}
```
